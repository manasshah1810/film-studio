# Whiteboard: failure modes

Check these before sending stills to review. Each was seen in a proof render or follows directly from the kit.

1. **Looks like a slide in a handwriting font.** No hatch, no ghost, no arrow on screen. Use a figure, object or chart panel at least every third panel so drawn marks outnumber typed ones.
2. **Highlighter hides the word.** Palette `highlight` too dark for the board. Pick a palette whose highlight passes with the dark role; never switch emphasis to a second colour.
3. **Board fills up and nothing leads.** More than one headline plus one visual. Split the panel; the board holds one sentence and one drawing.
4. **Writing finishes after the voice has moved on.** enter time is 26 frames: any panel under 1.6 s cuts off mid-stroke. Give written panels 2 s or more.
5. **Centred, symmetric composition.** Every panel given the same `anchor`. Remove it and let the style pick an edge start per panel.
6. **Three marker colours competing.** Cast uses primary and secondary and the chart adds a third. Keep to ink plus two markers plus the highlighter across the whole film.

## Quick self-check on a still
- None of: a photographic or clip-art hand holding a marker
- None of: flat colour fills, gradients, drop shadows, glows
- None of: centred symmetric layouts: content starts at an edge like real board writing
- None of: more than ink + 2 marker colours + 1 highlighter in a film
- All five signature moves from `style.md` appear somewhere in the film.
