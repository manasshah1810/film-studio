# Sketchbook: failure modes

Check these before sending stills to review. Each was seen in a proof render or follows directly from the kit.

1. **Handwriting too small on phones.** Script faces run narrow. Choose a pairing with `scale` above 1 or cut the headline to 4 words.
2. **Page looks clean and digital.** Only title and list panels used. Add figure, object or chart panels so pencil line and tape appear.
3. **Tape or marker hides text.** Highlight too strong on a dark-page palette. Use a light-paper palette for text-heavy films.
4. **Too many colours for a notebook.** Cast and chart together use both accents plus highlight. One pen colour plus one marker per panel.
5. **Reads as the whiteboard style.** Both use hand lettering. Sketchbook must show paper rules and tape; if neither is visible, the panel is too tight.
6. **Wobble becomes illegible on charts.** Chart with more than 5 x labels. Reduce points.

## Quick self-check on a still
- None of: perfect geometry: straight rules, true circles, uniform stroke width
- None of: opaque flat fills or any gradient
- None of: fades, slides, scale pops: marks are drawn on
- None of: clean sans-serif or serif type anywhere
- All five signature moves from `style.md` appear somewhere in the film.
